不用先学完一本书。每一题都有小课堂、分步提示和可运行的参考答案。

  1. 先学概念，再拆示例

    沿学习路线查看目标与先修知识。每题按「学概念 → 拆示例 → 引导练习 → 独立提交」推进。

  2. 根据题型编写程序

    函数题补全 solve 并 return 答案。ACM 标准输入题读取 input() 或 sys.stdin.buffer，用 print() 输出；页面会标明模式。SQL 题写查询。

  3. 运行示例，观察反馈

    Ctrl / ⌘ + Enter 运行，Ctrl / ⌘ + Shift + Enter 提交。失败时比较输入与输出，查看错误定位，回到概念再试。

  4. 独立练习，再用限时训练检验

    提交通过计入完成。历史保存代码快照；秋招与 ACM 训练提供持续倒计时和本场提交统计。熟练度需要迁移练习与长期复盘，不由做题数量保证。
